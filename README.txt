# Radhika Guest House Website

This is a static website prepared for `radhikaguesthouse.com`.

## Files
- `index.html` – website content
- `styles.css` – design and responsive layout
- `script.js` – small dynamic footer script
- `CNAME` – GitHub Pages custom domain

## Important
The photo areas are placeholders. Replace them with the guest house's real photos before the final launch.

## Free hosting
GitHub Pages can host this static website without separate paid hosting. After uploading the files to a GitHub repository, enable Pages and set the custom domain to `radhikaguesthouse.com`.

For the domain DNS, GitHub's current documentation provides the required A/AAAA records and recommends configuring the custom domain in GitHub Pages before changing DNS.

The site already includes:
- WhatsApp booking
- Call buttons
- Google Maps link
- Google review link
- Rooms
- Facilities
- Nearby temples
- Mobile responsive design
